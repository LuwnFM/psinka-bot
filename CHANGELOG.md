# 🐕 PsIInka Bot — Changelog

Все значимые изменения проекта фиксируются здесь.

## [0.4.3] — 2026-08-27 — RP Guard, Dice Rewrite & AI Routing

### ✨ Добавлено
- Единый `route_model_request()` для Groq, OpenRouter и g4f.
- Нормализация имён провайдеров и централизованная проверка исключённых моделей.
- `openrouter/free` как приоритетный бесплатный OpenRouter fallback.
- Автоматическое `pip install --upgrade g4f` при каждом запуске до первого `import g4f`.
- Модуль `cogs/text_admin.py` с RP-модерацией обычными сообщениями без `/` и `!`.
- RP-справка `Огласи устав Гвардии` с отображением прав на каждый приказ.
- Карцер как отдельный Discord timeout.
- Ручное освобождение из Темницы с отменой таймера и снятием роли `Спит`.
- Отдельные проценты длинных/коротких GM-постов по каждой найденной арке.
- Новые каталоги `logs/` и `state/` и модуль `core/paths.py`.
- GPLv3 `LICENSE`.

### 🎲 `/кубик`
- Поддержаны составные выражения с разными кубиками: `1d6+1d4`, `2d6+1d8+5`.
- Keep/drop, reroll, explode и target применяются к конкретному кубиковому терму.
- Формулы через `;` считаются и отправляются независимо, без общей суммы.
- Вывод показывает исходные броски, перебросы, взрывы, отбор, вклад термов и финальный итог.
- Алиасы поддерживаются внутри отдельных `;`-формул.
- Большая выдача автоматически разбивается на безопасные страницы.
- Добавлены строгие ошибки вместо молчаливого урезания/неожиданного разбора.
- Исправлены `k0`, `1d6+1d4`, мусорный текст, невозможные infinite-reroll пороги и другие edge cases.

### 🏠 `Недвижкаролл`
- Переведён на ту же 9-уровневую шкалу, что `Качестворолл`.
- Вероятности: 2 / 5 / 10 / 14 / 34 / 20 / 10 / 4 / 1%.
- Добавлены `Приемлемое`, `Отличное`, `Шедевр`.
- География и правила доступа не менялись.

### 🛡️ RP-модерация
- Темница (`Спит`) доступна: Администратор / Гвардеец / Старший Гвардеец.
- Карцер (Discord timeout) доступен: Администратор / Старший Гвардеец / Глава Гвардии Фаервелла.
- Kick переведён на RP-фразу и оставлен только Администраторам.
- Unban переведён на RP-фразу и доступен Администраторам / Главе Гвардии Фаервелла.
- Выдача/снятие обычных ролей переведены на RP-фразы и доступны только Администраторам.
- Добавлены проверки иерархии ролей и Discord permissions.

### 🔍 `/анализ`
- Формат выдачи сохранён.
- System prompt уточнён: оффтоп определяется по смыслу/контексту, а не только по скобкам и `//`.
- Короткое ролевое действие/реплика не считается оффтопом только из-за длины.
- Короткая неигровая/OOC-реплика может определяться и без специальных маркеров.
- Команда переведена на общий AI-router с сохранением своего порядка очереди.

### 💰 `/цены`
- Повторные номера лотов явно засчитываются как отдельные записи.
- Дедупликация оставлена только по одинаковому Discord `message_id`.
- В отчёте и XLSX разделены «повторные номера лотов (засчитаны)» и «повторные Discord-сообщения (пропущены)».

### 📊 `/подсчёт_постов`
- Общее соотношение длинных/коротких GM-постов сохранено.
- Добавлено такое же соотношение отдельно для каждой GM-арки.
- Остальная публичная выдача не заменялась.

### 🤖 AI / g4f / модели
- G4F переведён на актуальный `AsyncClient` с совместимым fallback на старый Client.
- Ошибки конкретного G4F provider не останавливают весь каскад.
- Сохранены `AuthenticationError`, `RequestLimitError`, `ModelNotFoundError`, `ProviderError`, timeout/401/404/429 fallback-ветки.
- Groq priority: `openai/gpt-oss-120b`, `openai/gpt-oss-20b`.
- OpenRouter priority начинается с `openrouter/free`.
- Старые списки исключений не удалены; исправлена область их применения по провайдерам.

### 📁 Пути и deployment
- `bot_errors.log` → `logs/bot_errors.log`.
- `analysis_debug.log` → `logs/analysis_debug.log`.
- `test_pending.csv` → `state/test_pending.csv`.
- `post_count_settings.json` → `state/post_count_settings.json`.
- Добавлена best-effort миграция старых runtime-файлов.
- `.env.example` приведён к реальным именам переменных, включая `REQUIRED_ROLE_ID`.
- README обновлён под GitHub → Cybrancee Auto Update.

### ❌ Удалено
- Выдача бана из текстового модераторского набора.
- Очистка сообщений из текстового модераторского набора.
- Старые сухие текстовые триггеры `админ помощь`, `кик`, `бан`, `разбан`, `мут`, `размут`, `очистить`, `выдать роль`, `снять роль`.
- Устаревшие активные G4F fallback-провайдеры, отсутствующие в актуальном реестре.
- MIT License (заменена на GPLv3).
- `__pycache__` из release-дерева.

### 🧪 Проверено
- `compileall` и AST для Python-файлов.
- 19 уникальных slash-команд.
- Целевые и ошибочные сценарии `/кубик`.
- 5000 сгенерированных корректных составных dice-формул.
- Пагинация больших dice-результатов.
- Шкала качества недвижимости = шкала `Качестворолл`, сумма весов 100%.
- Excel-база наёмников открывается как валидный XLSX-контейнер.
- Статические инварианты `/цены`, анализа оффтопа, GM-арок, RP-модерации, путей и g4f-bootstrap.

### ⚠️ Важные замечания
- `g4f` теперь intentionally rolling-latest: каждый restart может подтянуть новую версию PyPI, поэтому будущий несовместимый релиз g4f теоретически может потребовать правки.
- Live-проверка Discord API, реальных серверных permissions и внешних Groq/OpenRouter/g4f запросов требует production/test токенов и выполняется после деплоя.
